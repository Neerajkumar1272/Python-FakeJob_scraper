# Python-FakeJob_scraper
it is a Job scraping project. which scrapes Job Title, Company name, Location, Posted date and apply link.

# Introduction:-
This is a job scraping project. i have created this to fetch data from a website which is truly designed for practice web scraping. This python script extracts data from a website url="https://realpython.github.io/fake-jobs/".
It extracts mainly five elements from the given website which are Job Title, Company Name, Location, Date posted and  Apply link . it consists of 'three functions'(main, scrapping and csv data).


# Libraries:-
1. Python 3
2. BeautifulSoup
3. Requests
4. csv
5. lxml

# Functions:-

I have used Procedural Programming in it. It has three custom functions.
1. main()
2. scraping()
3. csv_data()

# Installation:

pip install -r requirements.txt
